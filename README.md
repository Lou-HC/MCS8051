# MS8051
For the MCS8051-Enchanced microcontroller.
### Loulan's Lucrative Library ###
   (furthermore: LLL)
 ---- ---- ----
 This file is property of Lou-HC on github.
 
 This file is meant to contain many files
 that increase the ease-of-use of the 8051
 microcontroller. Please remember to include
 the "8051.h" header files in any projects
 using the LLL. Furthermore, this library
 is made to be compiled using the SDCC
 (Small Device C Compiler). For usable
 results, please use that.

 The included 8051.h file was given by Mr.
 Piet van Huyssteenl; all credit goes to them.

All necessary documentation can be found at
the relevant function in the 
"LoulansLucrativeLibrary.c" file.

To add these files to any CodeBlocks:: file,
open your project and click "Project" in the
ribbon, thereafter "Add" and finally choose
LLL in your storage. Keep all other default
files.
 
 This was made for my university module in
 my first year.
